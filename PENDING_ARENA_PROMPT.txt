## 🎯 Questions for Arena Review:

1. **Volume Discrepancy Reconciliation**:
   - In our VM environment, direct requests to `fstream.binance.com` and `fapi.binance.com` face regional geo-blocking (HTTP 418 / disconnects).
   - How should we optimally synthesize or mirror the true Binance Futures 15m volume without violating rate limits or introducing latency drift?

2. **CVD Accumulation vs Baseline Drift**:
   - CoinGlass charts an absolute cumulative delta (e.g. +68.08K BTC for Futures, +7.49K BTC for Spot) with an exchange-specific historical baseline offset.
   - What is the most robust way to synchronize the continuous accumulator so that session reconnects do not cause step-function jumps or drift?

3. **TradingView ATR RMA Smoothing Alignment**:
   - We adjusted our pandas EMA span to `span = 2 * N - 1` (Wilder's RMA).
   - What specific True Range edge case (e.g. intra-bar unclosed candle high/low expansion) accounts for the remaining 5% variance against TradingView's Pine Script ATR engine?

4. **Hybrid Engine vs Pure API Architecture**:
   - Evaluate whether we should maintain a lightweight CDP background tab as an anchor baseline or execute 100% on the multi-exchange fallback chain (Binance Spot + OKX Perp + Bybit V5 + CoinGlass V4 API).
