Here's a Python script that calculates Fibonacci numbers using memoization:

# Fibonacci with Memoization

def fibonacci(n, memo={}):
    """
    Calculate the nth Fibonacci number using memoization.

    Args:
        n (int): The position in the Fibonacci sequence (0-indexed).
        memo (dict): A dictionary to store previously computed results.

    Returns:
        int: The nth Fibonacci number.
    """
    # Base cases
    if n <= 0:
        return 0
    if n == 1:
        return 1

    # Return cached result if available
    if n in memo:
        return memo[n]

    # Compute and store the result in memo
    memo[n] = fibonacci(n - 1, memo) + fibonacci(n - 2, memo)
    return memo[n]


# --- Main Execution ---
if __name__ == "__main__":
    print("Fibonacci Sequence with Memoization")
    print("=" * 40)

    # Print first 15 Fibonacci numbers
    for i in range(15):
        print(f"F({i:2}) = {fibonacci(i)}")

    print("\n--- Large Number Test ---")
    n = 50
    print(f"F({n}) = {fibonacci(n)}")
📝 How It Works

Base Cases:

F(0) = 0
F(1) = 1

Memoization:

A dictionary memo is used to cache previously computed results.
Before computing F(n), the function checks if the result is already in memo.
If yes, it returns the cached value instantly — no redundant recursion.
If no, it computes the value, stores it in memo, then returns it.

🔄 Alternative: Using functools.lru_cache

Python has a built-in decorator that handles memoization automatically:

Python
from functools import lru_cache

@lru_cache(maxsize=None)
def fibonacci(n):
    if n <= 0: return 0
    if n == 1: return 1
    return fibonacci(n - 1) + fibonacci(n - 2)

This is the most Pythonic and cleanest way to add memoization — no manual dictionary management needed!
